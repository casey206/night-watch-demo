《夜巡》 THE NIGHT WATCH
寶城人壽 ・ VVIP 顧客資料收集互動企劃
────────────────────────────────────────────

■ 一句話

今夜十二點，你是這座館的館長。
天亮之前，有一件國寶要找回來。


■ 先看這三個

1. 夜巡_DEMO_單檔版.html      ← 可實際遊玩的原型（建議用這個）
   直接用瀏覽器打開就能點，8 張場景圖已內嵌，
   不需要任何其他檔案，可以直接寄給客戶。
   完整體驗約 3 分鐘。

2. 夜巡_概念影片_長版.mp4      ← 64 秒概念影片
   六個鏡頭 ＋ 六張故事字卡。

3. 夜巡_企劃書.html            ← 完整企劃書
   受眾拆解、策略、Workflow、Consumer Journey、
   漏斗模型、顧問副軌、風險與待確認事項。


■ Demo 流程（18 個場景）

  封蠟委任狀
    → 輸入姓氏就任
    → 就任第一題（留一件東西在館裡）
    → 就任第二題（館規第三條・風險態度）
    → 十二點鐘響
    → 事件：翠玉白菜不見了
    → 關一 乾隆（蓋不蓋章 ＋ 健康追問）
    → 關二 宋徽宗（虧不虧）
    → 關三 蘇東坡（最慘那次吃了什麼）
    → 【L1 / L2 分層點】
    → 關四 兵馬俑（軍隊跟不跟主帥走）
    → 關五 溥儀（家業散在誰手上）
    → 關六 他留下的東西
    → 真相（白菜是去找它的孩子了）
    → 家庭結構（您身上有幾隻蟲）
    → 落款（交接紀錄附記）
    → 六點鐘響 ・ 結局
    → 交接紀錄 ＋ 實體交付
    → ★ 顧問後台

  ★ 最後那頁是提案時最重要的一頁：
    同一份體驗，客戶看到的是故事，顧問看到的是一張
    完整客戶檔案，並自動產出首次接觸的話術建議。
    建議話術會隨答案改變，不是寫死的。

  assets/   8 張場景圖（Demo 用）

■ 製作備註

  ・場景圖：Google Nano Banana Pro
  ・影片：Gemini Omni Flash（圖生影片）
  ・影片為六個獨立鏡頭串接，非連續運鏡。
    正式版需統一調色與配樂——目前各鏡頭環境音
    為模型各自生成。
  ・畫面刻意未出現館長正臉（門那顆只有手、
    空展櫃那顆是背影）。這對應企劃裡的美術方向：
    油畫／雕塑轉譯，不做寫實 AI 換臉，
    以規避肖像權疑慮與恐怖谷。
  ・字卡為 canvas 生成之宋體，正式版應換品牌字。


■ 上線前必須處理

  1. 文物 IP 授權（故宮／或改為架空「寶城典藏館」）
  2. 政治敏感度（文物南遷、溥儀台詞需逐句審）
  3. 保險法遵（招攬行為認定、個資告知、無保證性用語）
  4. 史料核校（乾隆享年、文物南遷數字等公開引用）
  5. 幽默鐵律：可以笑文物，一次都不能笑客戶。
